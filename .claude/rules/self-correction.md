# Self-Correction Protocol

When corrected by the user or when a mistake is identified:

1. Acknowledge specifically what went wrong
2. Propose a concise learning: `[LEARN] Category: One-line rule`
3. Wait for user approval before persisting
4. On approval, append to `memory/patterns.md` under the Learnings section

## Categories

Navigation, Editing, Testing, Git, Quality, Context, Architecture, Performance

## Format in patterns.md

```markdown
### [Category] Rule description
- **Mistake**: what went wrong
- **Correction**: what to do instead
- **Project**: project name
- **Date**: YYYY-MM-DD
```

## Trigger phrases

"remember this", "add to rules", "don't do that again", "retiens ça", "note ça"

Learnings compound over time. A correction today prevents the same mistake tomorrow.
