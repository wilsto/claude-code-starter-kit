# UX Workflow — Clarify → Prototype → Implement

Run the 3-phase UX workflow for any new page, screen, or significant UI change.

1. **Phase 1 — Clarification**: Read existing specs, identify unknowns, ask PO targeted WHAT/WHY questions. Never propose layout until answers are received.

2. **Phase 2 — Wireframe**: Produce a textual wireframe with justified UX decisions. Wait for PO approval before writing any code.

3. **Phase 3 — Implementation**: Decompose into components, apply design checklist, implement pixel-perfect. Self-review against approved wireframe.

See the full workflow in `~/.claude/skills/ux/SKILL.md`.
